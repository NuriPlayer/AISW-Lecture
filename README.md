# AISW-Lecture

2025년 1·2분기, 인공지능 프로젝트 동아리 **AISW** 활동의 일환으로 강의·발표한 자료를 모아 둔 저장소입니다.

Python 기초 지식이 있는 동아리원이 머신러닝과 딥러닝의 원리를 이해하고, 직접 모델을 구현해 개인·팀 프로젝트로 이어 갈 수 있도록 PPT와 실습 코드를 구성했습니다.

## 주요 내용

- **AI 기초**: 머신러닝과 딥러닝, 학습 방식, 퍼셉트론과 신경망
- **개발 환경과 라이브러리**: Python, NumPy, Pandas, Matplotlib, TensorFlow/Keras
- **모델 학습**: 데이터 전처리와 시각화, 손실함수, 모델 학습과 평가
- **이미지 분류**: Fashion MNIST 의류 분류, CNN을 활용한 개·고양이 분류
- **모델 개선**: 과적합 방지, 이미지 증강, MobileNetV2 전이학습, 모델 저장과 불러오기

## 자료 구성

| 자료 | 설명 |
| --- | --- |
| `AISW *.pptx` | 동아리 오리엔테이션 및 주차별 강의·발표 자료 |
| `*.py` | 기초 실습 및 예제 코드 |
| `*.ipynb` | 이미지 분류 등 딥러닝 실습 노트북 |
| `data/` | 실습용 데이터 및 관련 자료 |

강의 자료에는 준비 과정에서 수정한 여러 버전이 함께 포함되어 있습니다. 같은 주차의 자료는 버전 번호가 높은 파일부터 확인하시면 됩니다.
